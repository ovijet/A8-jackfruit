# SunCart – Summer Essentials Store

## Live Link

https://a8-jackfruit.vercel.app

## Purpose

SunCart is a modern eCommerce platform for summer products like sunglasses, outfits, skincare, and accessories.

## Features

- User authentication (Email + Google)
- Protected product details page
- Redirect after login
- Responsive design
- Profile & update profile
- JSON-based product data

## Tech Stack

- Next.js
- Tailwind CSS
- DaisyUI / HeroUI
- BetterAuth

## NPM Packages
- react-icons
- react-toastify

## Environment Variables

- API keys stored in `.env.local`
